Version: 2.0

# 1. 目的

本書は、MVPでは実装しない機能を整理し、将来の開発計画を管理することを目的とする。

本書は将来機能一覧の正本である。`01_Requirements.md` はMVP対象外の概要のみを記載し、詳細は本書へ集約する。

本書に記載された機能は、要件定義・設計・実装・テストの対象外とする。

## 1.1 MVPで実装済みの機能を記載しない

以下はMVPで実装するため、本書の対象外である。混同しないこと。

| 機能         | MVPでの扱い                              |
| ---------- | ------------------------------------ |
| チーム招待      | MVPの正式仕様（ADR-013）。参加は招待制のみ           |
| 勝率・試合数の表示  | `team_ranking_view` で提供              |
| 試合一覧・試合詳細  | Match List / Match Detail として提供      |
| ダークモード     | MVPの対象（`05_Frontend.md` 14.1）        |
| 監査ログ       | MVPの対象（ADR-017）                      |
| レートリセット    | MVPの対象。ただしシーズン機能ではない                 |

# 2. 優先度

| 優先度    | 説明                 |
| ------ | ------------------ |
| High   | MVP完了後に優先して検討する機能  |
| Medium | 利用状況を見ながら追加を検討する機能 |
| Low    | 将来的な拡張機能・アイデア      |

# 3. High Priority

## シーズン制

* シーズン開始・終了
* シーズン別ランキング
* シーズン履歴

---

## レート推移の可視化

* レート推移グラフ
* 勝率の推移
* 対戦ごとの変動一覧

`rating_history` テーブル自体はMVPで実装済みである。本項目はその**可視化**を指す。

---

## 異議申し立て・管理者裁定

* 確定済み試合への異議申し立て
* 管理者による結果の訂正
* 訂正に伴うレートの再計算

MVPでは確定後の変更手段を提供しない。誤った結果は拒否（`reject-match`）により確定前に防ぐ。

* 外部リンク

## プレイヤープロフィール

* アバター表示

* 個人成績
* プレイ履歴

---

## 通知機能

* ブラウザ通知
* 試合成立通知
* 招待通知
* システム通知

# 6. 保留事項

以下は現時点では採用可否を決定しない。

* モバイルアプリ化
* PWA対応
* AIによる試合分析
* AIチャットサポート
* Steam以外の認証プロバイダー対応

---

# 7. 採用方針

* MVPの機能追加は原則行わない。
* 新機能は本書へ追加後、要件定義・設計・DecisionLogを経て採用を判断する。
* 既存仕様との互換性を維持する。

---

# 8. AI実装ルール

* 本書に記載された機能はMVPでは実装しない。
* AIは未実装機能を推測して実装してはならない。
* 新機能を実装する場合は、本書および関連設計書を更新してから実装する。
