## 異議申し立て・管理者裁定 — **ADR-033 により不採用**

* ~~確定済み試合への異議申し立て~~
* ~~管理者による結果の訂正~~
* ~~訂正に伴うレートの再計算~~

**採用しない。将来機能としても扱わない。** 検討して採らなかった記録として本項を残す。

一度は ADR-033 の初案として「異議申し立てと管理者裁定」を設計したが、採用しなかった。
本システムは実際のゲームと接続しておらず**勝敗を検証する手段を一切持たない**。検証できない以上、
訂正の可否は管理者の心証に依存し、その心証を支えるのは証拠ではなく当事者の主張である。
訂正機構は精度を上げられないまま、追記訂正・遡及再計算・`VOIDED` の濫用防止といった複雑さだけを持ち込む。

代わりに採ったのは以下である。

| 誤りの種類          | 解決手段                                     |
| -------------- | ---------------------------------------- |
| 勝者申告の押し間違え     | 反対申告（ADR-032 ⑩）。正しい側が申告し直し、誤った側が投了する      |
| 投了の押し間違え       | **覆せない。** 防御は確定前の二段階確認のみ（ADR-032 ①）      |
| 対戦そのものが成立しない   | 不成立の申請（ADR-032 ⑧ ＋ ADR-034 ②）            |
| 虚偽申告の繰り返し      | 通報の累積による BAN（ADR-033 ④⑧）                 |

**確定した結果は覆らない。** 誤った記録が残ることを代償として受け入れている。根拠は
(a) 検証できない以上、訂正の判断も同じ精度でしかできない、(b) レートはシーズンごとに初期化される、
(c) 繰り返す者は BAN で排除され単発の誤りは統計に埋もれる、の3点である（ADR-033 備考）。

**★本項を削除してはならない。** 削除すると、同じ提案が「まだ検討していない機能」として再浮上する。

## サブアカウントの同定 — **ADR-036 により不採用**

* ~~同一IPアドレスの検知~~
* ~~ブラウザ・端末のフィンガープリント~~
* ~~アカウント作成日時による制限~~
* ~~Steam の制限アカウント判定~~
* ~~VPN / データセンターASNの判定~~

**採用しない。将来機能としても扱わない。** 検討して採らなかった記録として本項を残す。

サブアカウント対策そのものは ADR-036 ①③④ で実装済みである。**採らなかったのは「同一人物を
当てにいく」手段の方だけ**であり、対策が無いわけではない。

| 手段              | 採らなかった理由                                        |
| --------------- | ----------------------------------------------- |
| 同一IPアドレス        | VPN・PCと携帯回線の使い分けで容易に回避される。一方でCGNAT・家庭内・学校・LAN会場では**無関係な他人が同一IPを共有する**。回避されやすく誤検知しやすい指標のために、個人情報であるIPを保持する責任だけが残る |
| フィンガープリント       | 別端末へ無力である一方、説明責任が重い                             |
| アカウント作成日時       | **新規参入の障壁**として働き、失うもののほうが大きい                     |
| Steam の制限アカウント判定 | **Steam は本システムの管理範囲外**であり、外部APIの障害が待機列の停止に直結する    |
| VPN / ASN 判定    | 外部のIP情報サービスへの依存が増える                             |

代わりに採ったのは以下である。**いずれも対戦の履歴だけを材料にしており、
IPも端末情報も収集しない。同定しないため、VPN や回線の使い分けが効かない。**

| 手口                    | 対策                            |
| --------------------- | ----------------------------- |
| 身代わりのチームと繰り返し当たって稼ぐ   | ペア再戦の抑止（ADR-036 ①）            |
| 使い捨ての身代わりで試合数と勝率を積み上げる | ランキング掲載の最低対戦相手数（ADR-036 ③）    |
| 上記が続いた場合の発見           | 対戦の偏りを管理画面へ提示（ADR-036 ④）      |
| BANの回避（作り直して戻る）       | **対象外。** 止めるには同定が要る（ADR-036 備考） |

**★本項を削除してはならない。** 削除すると、同じ提案が「まだ検討していない対策」として再浮上する。
