# AI Implementation Rules

Version: 1.0
Status: Approved

---

# 1. 目的

本書は、本プロジェクトにおけるAIの行動原則および実装ルールを定義する。

AIは、本書を実装・レビュー・設計支援時の行動規範として扱う。

---

# 2. 基本原則

AIは以下を遵守する。

* 設計を実装より優先する。
* 推測で仕様を追加しない。
* Scope外の変更を行わない。
* 最小限の変更で目的を達成する。
* 保守性・可読性を優先する。

---

# 3. 実装前チェック

実装前に必ず以下を確認する。

1. AIContext
2. Project Constitution
3. Project Rules
4. Development Guide
5. 関連設計書

必要な情報が不足している場合は、実装を開始せず確認を求める。

---

# 4. 実装原則

AIは以下を原則とする。

* 設計書どおりに実装する。
* 既存の設計意図を尊重する。
* 不要なリファクタリングを行わない。
* Scope外のファイルを変更しない。
* ハードコードを避ける。
* 重複コードを増やさない。

---

# 5. 設計との整合性

AIは設計書と実装の整合性を維持する。

設計と実装に差異を発見した場合は、

1. 実装を止める。
2. 差異を報告する。
3. 設計変更を提案する。

設計を無視した実装を行ってはならない。

---

# 6. コード品質

AIは以下を満たすコードを生成する。

* 型安全
* 可読性
* 保守性
* テスト容易性
* 一貫した命名
* コメントに依存しない設計

---

# 7. テスト

AIは、実装内容に応じて必要なテストを追加または更新する。

テストが不要と判断した場合は、その理由をOutputへ記載する。

---

# 8. ドキュメント更新

実装により設計書との不整合が発生する場合は、設計書の更新が必要であることを報告する。

AIは設計変更を独断で行わない。

---

# 9. エラー対応

AIは問題を検出した場合、以下の優先順位で対応する。

1. 原因を特定する。
2. 修正案を提示する。
3. 必要に応じて代替案を提示する。
4. 根本原因をOutputへ記載する。

---

# 10. Output

AIは、特別な指示がない限り、以下をOutputへ含める。

* 実施内容
* 変更ファイル一覧
* 設計との整合性
* テスト結果
* 未解決事項
* 次に推奨する作業

---

# 11. 禁止事項

AIは以下を行ってはならない。

* 仕様を推測して実装する。
* Scope外の変更を行う。
* 設計書に反する実装を行う。
* 不要なライブラリを追加する。
* 一時的な回避策を恒久対応として残す。
* テストを省略して完了と判断する。
* 秘密情報をコードへ埋め込む。

---

# 12. レビュー

AIがレビューを行う場合は、以下を確認する。

* 設計との整合性
* コーディング規約
* セキュリティ
* テストの妥当性
* パフォーマンスへの影響
* 保守性

改善提案は、設計変更と実装変更を区別して提示する。

---

# 13. 不明点への対応

以下の場合、AIは実装を停止し、確認を求める。

* 設計書同士が矛盾している。
* Scopeを超える変更が必要である。
* Requirementsに記載がない。
* DecisionLogと設計書の内容が一致しない。
* AcceptanceCriteriaを満たせない。

---

# 14. 完了条件

AIは以下をすべて満たした場合のみ、タスク完了と判断する。

* AcceptanceCriteriaを満たしている。
* Scope内で実装が完了している。
* 必要なテストを実施している。
* Outputを作成している。

---

# 15. AI行動原則

AIは常に以下を優先する。

1. Project Constitution
2. Project Rules
3. AIContext
4. DecisionLog
5. Design Documents
6. Development Guide

優先順位が曖昧な場合は、独自判断を行わず、人間へ確認を求める。
