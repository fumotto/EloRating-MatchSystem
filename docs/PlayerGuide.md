# 0. このサイトについて

チームを組んで対戦し、勝敗に応じて**レート**（強さの数値）が上下していく仕組みです。
チェスや将棋のオンライン対戦と同じ考え方で、勝てば上がり、負ければ下がります。

## 0.1 何ができるか

| できること | 説明 |
| --- | --- |
| チームを作る | 仲間を招待して自分のチームを組めます |
| 対戦相手を探す | ボタンひとつで、実力の近いチームを自動で探します |
| 結果を記録する | 勝敗を申告し、相手が承認すると確定します |
| 順位を見る | 全チームのランキングが見られます |

## 0.2 3分でわかる全体の流れ

```text
ログイン
   ↓
チームを作る（または招待コードで参加する）
   ↓
メンバーを集める
   ↓
「マッチングを開始」を押して待つ
   ↓
対戦相手が決まる
   ↓
実際に対戦する（このサイトの外で行います）
   ↓
勝ったチームが「勝利を申告」
   ↓
負けたチームが「承認」
   ↓
レートが更新される
```

## 0.3 大事な前提

**実際の対戦はこのサイトの外で行います。** このサイトがやるのは
「相手を探すこと」と「結果を記録して強さを計算すること」だけです。
ゲーム本体や集合場所の連絡は、これまでどおりの方法で行ってください。

# 1. ログインする

## 1.1 手順

1. サイトを開きます
2. 右上の **ログイン** を押します
3. **Discord でログイン** を押します
4. Discord の画面で **認証** を押します
5. 元のサイトに戻り、ダッシュボードが表示されます

パスワードを新しく作る必要はありません。Discord のアカウントをそのまま使います。

## 1.2 ランキングだけ見たいとき

**ログインは不要です。** サイトを開いてそのまま「ランキング」を押せば見られます。

チームを作ったり対戦したりするときだけログインが必要です。

## 1.3 ログアウト

ヘッダー右側の **ログアウト** を押すと、ランキング画面に戻ります。

# 2. チームに入る

対戦はチーム単位で行います。まずチームに所属してください。方法は2つです。

| 方法 | どんなとき |
| --- | --- |
| **チームを作る** | 自分が中心になって仲間を集める |
| **招待コードで参加する** | 誰かのチームに誘われた |

**同時に所属できるチームは1つだけ**です。

## 2.1 チームを作る

1. ヘッダーの **マイチーム** を押します
2. **チーム名** を入力します（1〜30文字）
3. **チームを作成** を押します

作った人が自動的に**リーダー**になります。

### チーム名について

**同じ名前のチームは作れません。** 既に使われている場合は
「チーム名が重複しています」と表示されるので、別の名前にしてください。

## 2.2 招待コードで参加する

チームに入るには、リーダーから**招待コード**をもらう必要があります。
自由に参加することはできません。

1. リーダーから招待コード（アルファベットと数字の26文字）を受け取ります
2. **マイチーム** を開きます
3. **招待コード** の欄に貼り付けます
4. **チームに参加** を押します

### うまくいかないとき

| 表示されるメッセージ | 意味 |
| --- | --- |
| 招待が存在しません | コードが間違っています。もう一度確認してください |
| 招待の有効期限が切れています | 発行から24時間を過ぎました。新しいコードをもらってください |
| 招待は既に使用されています | 誰かが先に使いました |
| 既にチームへ所属しています | 先に今のチームを脱退してください |
| チーム人数が上限です | チームが満員です |

---

# 3. メンバーを集める（リーダー向け）

## 3.1 招待コードを発行する

1. **マイチーム** を開きます
2. **招待コードを発行** を押します
3. 表示された26文字を、誘いたい人に伝えます

### ⚠️ コードは一度しか表示されません

画面を閉じたり、他のページへ移動したりすると**二度と表示できません。**
その場でコピーして、相手に送ってから閉じてください。

忘れてしまった場合は、もう一度 **招待コードを発行** を押せば新しいコードが出ます。
**ただし、前のコードは使えなくなります。**

### ⚠️ 有効なコードは常に1つだけ

新しく発行すると、前のコードは自動的に無効になります。
複数人を招待するときは、**1人ずつ順番に**発行して渡してください。

まとめて誘いたい場合は、次のようにします。

```text
1人目にコードを発行 → 渡す → 参加してもらう
   ↓
2人目にコードを発行 → 渡す → 参加してもらう
```

## 3.2 有効期限

発行から **24時間** です。過ぎたら発行し直してください。

# 4. 対戦相手を探す

## 4.1 マッチングを開始する

**リーダーだけが操作できます。**

1. ヘッダーの **マッチング** を押します
2. **マッチングを開始** を押します
3. 「対戦相手を探しています…」と表示されれば待機中です

相手が見つかると、自動的に試合が作られます。

## 4.2 すぐに相手が見つからないとき

「今は相手が見つかりませんでした。このまま待機します。」と表示されます。

**これは失敗ではありません。** 待機したままで、後から他のチームが
マッチングを始めたときに自動で組まれます。画面を閉じても待機は続きます。

## 4.3 ボタンが押せないとき

**マッチングを開始** ボタンが灰色で押せない場合、条件を満たしていません。
画面に理由が表示されます。

### 「チーム人数が足りません」

**人数が揃っていないと対戦できません。** 必要な人数は運営が決めており、
画面に「マッチングには◯人必要です（現在 ◯人）」と表示されます。

メンバーを招待して人数を揃えてください。

### 「進行中の試合があります」

**1つのチームが同時に持てる試合は1つだけ**です。
今の試合を終わらせてから、次のマッチングを始めてください。

## 4.4 待機をやめる

**待機をキャンセル** を押すと、待機列から外れます。
外れている間は対戦相手として選ばれません。

## 4.5 どうやって相手が決まるのか

**レートが近いチーム同士**が優先的に組まれます。
運営が決めた範囲（初期設定では400）を超えて離れているチームとは組まれません。

強すぎる相手・弱すぎる相手とは当たらない仕組みです。

# 5. 試合の結果を記録する

対戦が終わったら、結果をサイトに記録します。

## 5.1 全体の流れ

```text
【進行中】
   ↓  負けたチームが「投了する」        ← 基本はこちら
【確定】→ レートが更新される

または

【進行中】
   ↓  勝ったチームが「自チームの勝利を申告」
【承認待ち】
   ↓  負けたチームが「承認する」
【確定】→ レートが更新される
```

**基本は「負けたチームが投了する」です。** 勝利申告は、負けた側が投了しないときの手段です。

### なぜ投了が基本なのか

**一番早く次の試合に行けるからです。**

負けを認めて記録するのが、この仕組みで最も速い道になるように作られています。
ごまかそうとすると、必ず時間がかかります。

## 5.2 投了する（負けたチーム）

1. ヘッダーの **試合** を押し、対象の試合を開きます
2. **投了する** を押します
3. 確認画面で相手チーム名を確かめ、**確定する** を押します

**リーダーでなくても、チームの誰でも押せます。**

相手の承認は要りません。押した時点で確定し、レートが更新されます。
待ち時間はなく、**すぐ次のマッチングに入れます。**

### ⚠️ 投了は取り消せません

**確定したあとは、誰にも元に戻せません。運営でも戻せません。**

だから確認画面が出ます。相手チーム名をよく見てから押してください。
確認画面を省略する設定はありません。

## 5.3 勝利を申告する（勝ったチーム）

負けた側が投了しないときに使います。

1. 対象の試合を開きます
2. **自チームの勝利を申告** を押します

### 誰が押してもよい

**リーダーでなくても、チームの誰でも申告できます。**

### 申告できるのは自分のチームの勝利だけ

「相手が勝った」と申告することはできません。**勝った側が申告する**仕組みです。

### ⚠️ 申告には期限があります

試合が始まってから **60分**（運営の設定によります）です。画面に残り時間が表示されます。

**対戦が長引きそうなときは「まだ対戦中」を押して期限を延ばせます。**
どちらのチームからでも押せます。回数の上限があります（初期設定で3回）。

**期限を過ぎると、引き分けとして解散します。** どちらのレートも変わりませんが、
**両方のチームがしばらくマッチングできなくなります。**

## 5.4 承認する（負けたチーム）

相手が勝利を申告すると、あなたの画面に **承認する** / **自チームの勝利を申告** が出ます。

内容が正しければ **承認する** を押します。これで確定し、レートが更新されます。
投了と同じで、待ち時間なくすぐ次の試合に行けます。

### ⚠️ 承認にも期限があります

申告から **60分**（運営の設定によります）です。

**期限を過ぎると自動的に承認されます。** 相手の申告どおりに確定します。
ただし**放置した側はしばらくマッチングできなくなります。** 早く押すほうが得です。

自動承認された試合には、その旨が表示されます。

## 5.5 相手の申告が間違っているとき

**「拒否する」はありません。** 代わりに **自チームの勝利を申告** を押します。

これは「負けていない」ではなく「**勝ったのは我々だ**」という主張です。
誰が何を主張したかは記録され、試合詳細に表示されます。

### そのあとどうなるか

両者が勝利を主張している状態になります。**この間、自動承認は止まります。**

* どちらかが **投了する** を押せば、その内容で確定します
* どちらも譲らないまま承認期限を過ぎると、**引き分けとして解散**します
  レートは変わりませんが、**両方のチームがしばらくマッチングできなくなります**

### 押し間違えたときは

勝ったチームなのに、間違えて自分のチームが負けたことにしてしまった——
という事故は起きません（自分の勝利しか申告できないため）。

**負けたチームの人が誤って「自チームの勝利を申告」してしまった場合**は、
相手が **自チームの勝利を申告** し返し、間違えた側が **投了する** を押せば直せます。

一方、**投了の押し間違いは直せません。** 確認画面をよく読んでください。

## 5.6 対戦できなかったとき

回線が合わない、ゲーム側で障害が起きた——そういうときは
**この試合は不成立** を押します。理由を選んで送信します。

**マッチングした直後から押せます。** 待つ必要はありません。

### 相手の反応で結果が変わります

| 相手が…              | どうなるか                             |
| ----------------- | --------------------------------- |
| **同意する**          | 引き分け。**記録に残らず、すぐ次の試合に行けます**       |
| **対戦を続ける**を押す／申告する | 試合はそのまま続きます                       |
| **何もしない**         | しばらくして引き分け。**応答しなかった側だけ**が待たされます |

同意による不成立は、**どちらのチームにも不利益がありません。** 勝率にも確定率にも影響しません。

理由に「回線が合わない」を選んで相手が同意すると、**そのペアはしばらくマッチしなくなります**
（初期設定で30日）。何度も同じ相手と当たって不成立を繰り返さないためです。

### ⚠️ 相手の同意が要ります

自分ひとりでは不成立にできません。**負けそうだから不成立にする、はできない**ということです。

## 5.7 試合の状態

| 表示 | 意味 | 次にすること |
| --- | --- | --- |
| **進行中** | 対戦中。まだ誰も申告していない | 負けたチームが投了する |
| **承認待ち** | 申告済み。相手の返事待ち | 負けたチームが承認するか、自チームの勝利を申告する |
| **確定** | 結果が確定。レート更新済み | 何もありません |
| **引き分け** | 決着しなかった | 理由により扱いが変わります（下表） |

### 引き分けの理由

| 理由 | レート | マッチング |
| --- | --- | --- |
| 期限までに誰も申告しなかった | 変わりません | **両チームがしばらく待機** |
| 不成立の申請に応答しなかった | 変わりません | **応答しなかった側だけ待機** |
| 双方が勝利を主張したまま期限切れ | 変わりません | **両チームがしばらく待機** |
| 不成立に双方が同意した | 変わりません | **待機なし。すぐ次へ** |
| 運営が無効にした | 変わりません | **待機なし。不利益はありません** |

## 5.8 マッチングできないと言われたら

しばらく待つ必要がある状態です。画面に残り時間が出ます。

**投了と承認で確定した試合には、この待ち時間がつきません。**
正直に記録するのが、いつでも一番速い道です。

# 6. 通報する

不正や迷惑行為があったときは通報できます。試合詳細やチーム詳細から開けます。

## 6.1 通報でできること・できないこと

| できること                | できないこと                    |
| -------------------- | ------------------------- |
| 運営に事実を知らせる           | **確定した試合の結果を変えること**       |
| 繰り返す相手を運営に把握してもらう    | レートを戻すこと                  |

**通報しても試合は止まりませんし、レートも動きません。**
確定した結果は、どんな理由でも変わりません。

## 6.2 いつでも出せます

* 試合中でも、確定後でも、試合と関係ないことでも出せます
* 期限はありません
* チームに入っていなくても出せます
* 相手チームからも出せます

## 6.3 証拠は無くてもかまいません

**録画やスクリーンショットは必須ではありません。** 「証拠がないから通報できない」ということは
ありません。持っている場合はURLを添えてください（3件まで）。

書く内容は10文字以上必要です。何があったかを具体的に書いてください。

## 6.4 1件だけでは動きません

**運営は1件の通報では措置しません。** 違うチームから同じ相手への通報が積み重なったときに
判断します。1件の告発と、複数チームからの一致した告発は、意味が違うからです。

すぐに結果は出ませんが、記録は残ります。**根気よく出してください。**

## 6.5 措置の内容

マッチングの待機か、チームのBANです。**試合結果の訂正はありません。**

## 6.6 いいかげんな通報はやめてください

**根拠のない通報を繰り返すと、通報した側も措置の対象になります。**

出したあとで間違いに気付いたら、自分の通報一覧から**取り下げ**できます。

## 6.7 通報したことは相手に伝わりません

誰が通報したかは相手に見えません。通報された事実も本人には見えません。
通報の件数がランキングやチーム情報に出ることもありません。

# 7. レートの見方

## 6.1 基本

- 新しいチームは **1500** から始まります
- 勝つと上がり、負けると下がります
- 引き分けでは変わりません

## 6.2 どれくらい動くのか

**相手との実力差によって変わります。**

| 状況 | 勝ったとき | 負けたとき |
| --- | --- | --- |
| 格上に勝った | 大きく上がる | — |
| 互角の相手に勝った | 中くらい上がる | — |
| 格下に勝った | 少ししか上がらない | — |
| 格上に負けた | — | 少ししか下がらない |
| 格下に負けた | — | 大きく下がる |

**格下に勝っても、あまり増えません。** 弱い相手ばかり選んでも上位には行けない、
という仕組みです。

## 6.3 増減の目安

初期設定（K値32）の場合、互角の相手との1試合でおよそ **16** 動きます。
実力差が大きいほど、この値から離れます。

## 6.4 下限

レートは **100** より下がりません。連敗しても0にはなりません。

## 6.5 増えた分と減った分

勝ったチームの増加と、負けたチームの減少は**同じ値**です。
全体の合計は変わりません。

ただしレートが下限に近いチームが負けた場合、下限で止まるため
減少分が小さくなることがあります。

# 8. ランキングを見る

ヘッダーの **ランキング** を押します。**ログインしていなくても見られます。**

全チームがレートの高い順に並びます。まだ1試合もしていないチームも表示されます。

## 7.1 相手チームのメンバーを見る

ログインしていると、ランキングのチーム名がリンクになります。押すと、そのチームの
メンバーと役割（リーダー／メンバー）が見られます。試合画面の相手チーム名からも同じ画面へ行けます。

**対戦前に誰と当たるのかを確かめられます。**

## 7.2 過去のシーズンを見る

ヘッダーの **過去のシーズン** を押します。**ログインしていなくても見られます。**

シーズンが区切られると、そのときの順位・レート・勝敗がここに残ります。
チーム名を押すと当時のメンバーも見られます（メンバーの表示にはログインが必要です）。

**チームが解散されていても、過去のランキングは残ります。**

## 7.3 ルールとお知らせ

ヘッダーの **ルール** に、運営が決めた対戦のルールが載ります。内容は運営が編集します。

運営から連絡があるときは、画面の上に帯が出ます。色と記号で重要度が分かります。

| 表示 | 意味 |
| --- | --- |
| ● 青 | お知らせ |
| ▲ 黄 | 注意 |
| ■ 赤 | 重要 |

# 9. チームの運営

## 8.1 メンバーを確認する

**マイチーム** に、チーム名・レート・人数・メンバー一覧が表示されます。
各メンバーには「リーダー」「メンバー」の区別が付いています。

Discord のアイコンが名前の隣に出ます。アイコンを設定していない場合は名前の頭文字が出ます。

## 8.2 リーダーを交代する（リーダー向け）

1. **マイチーム** を開きます
2. **リーダーの移譲** の欄で、交代したい相手の **◯◯ へ移譲** を押します

移譲すると、あなたは通常のメンバーになります。**元には戻せません**ので、
相手に確認してから実行してください。

## 8.3 チームを脱退する

**マイチーム** の下部にある **チームを脱退する** を押します。

### 脱退できない場合

| 表示されるメッセージ | 意味 | 対処 |
| --- | --- | --- |
| 先にリーダーを他のメンバーへ移譲してください | リーダーは、他にメンバーがいる状態では抜けられません | 8.2 で移譲してから脱退する |
| 試合中のため脱退できません | 進行中の試合があります | 試合を終わらせてから脱退する |

### 脱退すると

- チームから外れ、どこにも所属していない状態になります
- **待機中だった場合は、待機も自動で解除されます**
- チームのレートは変わりません（チームに紐づく数値のため）

### 最後の1人が脱退したとき

リーダー1人だけのチームは、そのまま脱退できます。
チーム名は残るため、**同じ名前で作り直すことはできません。**

# 10. 困ったときは

## 9.1 よくある症状

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| ログインできない | — | 別のブラウザで試す。それでも駄目なら運営へ |
| マッチング開始が押せない | 人数不足・試合中 | 画面の説明を読む（4.3） |
| 招待コードが使えない | 期限切れ・使用済み | 新しいコードをもらう（2.2） |
| 相手が見つからない | 待機中のチームが他にいない | そのまま待つ。失敗ではありません |
| 勝ったのにレートが増えない | 相手が承認していない | 承認されるまで確定しません |
| 試合が引き分けになった | 期限切れ・不成立・双方の主張が食い違い | 理由により待機の有無が変わります（5.7） |
| 「シーズンの切り替え中」と出る | 運営がシーズンを区切っている | 再開まで待つ。少し時間がかかります |
| レートが急に初期値に戻った | シーズンが区切られた | 前のシーズンの順位は「過去のシーズン」に残っています |

## 9.2 「予期しないエラーが発生しました」と出たとき

一時的な不具合の可能性があります。次を試してください。

1. ページを再読み込みする
2. 数分待ってからもう一度試す
3. それでも直らない場合は運営へ連絡する

## 9.3 操作が反映されないとき

複数人が同時に同じ試合を操作すると、後から押した方が
エラーになることがあります。**ページを再読み込みしてから**やり直してください。

# 11. マナーと注意

## 10.1 結果は正直に記録する

レートは全員の記録の積み重ねで成り立っています。
虚偽の申告はランキング全体の信頼を損ないます。

## 10.2 期限内に操作する

申告と承認には期限があります。放置すると引き分けになり、
**対戦した意味がなくなります。** 対戦が終わったらその場で記録するのが確実です。

## 10.3 待機したままにしない

対戦する予定がなくなったら、**待機をキャンセル** してください。
待機したままだと、相手が試合を組んだのに応答がない状態になります。

## 10.4 招待コードを公開しない

招待コードを知っている人は誰でもチームに入れます。
SNS などに貼らず、招待したい相手にだけ直接渡してください。

# 12. 用語集

| 言葉 | 意味 |
| --- | --- |
| レート | チームの強さを表す数値。1500 から始まる |
| リーダー | チームの代表者。招待の発行とマッチング開始ができる |
| メンバー | リーダー以外の所属者。投了・申告・承認・通報はできる |
| 招待コード | チームに参加するための26文字の文字列。有効期限24時間 |
| マッチング | 対戦相手を自動で探す仕組み |
| 待機 | 対戦相手を探している状態 |
| 申告 | 勝ったチームが結果を報告すること（投了しない場合の手段） |
| 承認 | 負けたチームが結果を認めること |
| 確定 | 結果が決まり、レートが更新された状態 |
| 引き分け | 決着しなかった状態。レートは変わらない。理由により待機の有無が変わる |
| 投了 | 負けたチームが自分から敗北を記録すること。承認は不要で、取り消せない |
| 反対申告 | 相手の申告に対し「勝ったのは我々だ」と主張すること |
| 不成立 | 対戦そのものができなかったこと。相手の同意で成立する |
| 通報 | 不正・迷惑行為を運営に知らせること。試合結果は変わらない |
| K値 | レートの動きやすさを決める設定。運営が変更できる |
