# 0. このサイトについて

チームを組んで対戦し、勝敗に応じて**レート**（強さの数値）が上下していく仕組みです。
チェスや将棋のオンライン対戦と同じ考え方で、勝てば上がり、負ければ下がります。

## 0.1 何ができるか

| できること | 説明 |
| --- | --- |
| チームを作る | 仲間を招待して自分のチームを組めます |
| 対戦相手を探す | ボタンひとつで、実力の近いチームを自動で探します |
| 結果を記録する | 勝敗を申告し、相手が承認すると確定します |
| 順位を見る | 全チームのランキングが見られます |

## 0.2 3分でわかる全体の流れ

```text
ログイン
   ↓
チームを作る（または招待コードで参加する）
   ↓
メンバーを集める
   ↓
「マッチングを開始」を押して待つ
   ↓
対戦相手が決まる
   ↓
実際に対戦する（このサイトの外で行います）
   ↓
勝ったチームが「勝利を申告」
   ↓
負けたチームが「承認」
   ↓
レートが更新される
```

## 0.3 大事な前提

**実際の対戦はこのサイトの外で行います。** このサイトがやるのは
「相手を探すこと」と「結果を記録して強さを計算すること」だけです。
ゲーム本体や集合場所の連絡は、これまでどおりの方法で行ってください。

# 1. ログインする

## 1.1 手順

1. サイトを開きます
2. 右上の **ログイン** を押します
3. **Discord でログイン** を押します
4. Discord の画面で **認証** を押します
5. 元のサイトに戻り、ダッシュボードが表示されます

パスワードを新しく作る必要はありません。Discord のアカウントをそのまま使います。

## 1.2 ランキングだけ見たいとき

**ログインは不要です。** サイトを開いてそのまま「ランキング」を押せば見られます。

チームを作ったり対戦したりするときだけログインが必要です。

## 1.3 ログアウト

ヘッダー右側の **ログアウト** を押すと、ランキング画面に戻ります。

# 2. チームに入る

対戦はチーム単位で行います。まずチームに所属してください。方法は2つです。

| 方法 | どんなとき |
| --- | --- |
| **チームを作る** | 自分が中心になって仲間を集める |
| **招待コードで参加する** | 誰かのチームに誘われた |

**同時に所属できるチームは1つだけ**です。

## 2.1 チームを作る

1. ヘッダーの **マイチーム** を押します
2. **チーム名** を入力します（1〜30文字）
3. **チームを作成** を押します

作った人が自動的に**リーダー**になります。

### チーム名について

**同じ名前のチームは作れません。** 既に使われている場合は
「チーム名が重複しています」と表示されるので、別の名前にしてください。

## 2.2 招待コードで参加する

チームに入るには、リーダーから**招待コード**をもらう必要があります。
自由に参加することはできません。

1. リーダーから招待コード（アルファベットと数字の26文字）を受け取ります
2. **マイチーム** を開きます
3. **招待コード** の欄に貼り付けます
4. **チームに参加** を押します

### うまくいかないとき

| 表示されるメッセージ | 意味 |
| --- | --- |
| 招待が存在しません | コードが間違っています。もう一度確認してください |
| 招待の有効期限が切れています | 発行から24時間を過ぎました。新しいコードをもらってください |
| 招待は既に使用されています | 誰かが先に使いました |
| 既にチームへ所属しています | 先に今のチームを脱退してください |
| チーム人数が上限です | チームが満員です |

---

# 3. メンバーを集める（リーダー向け）

## 3.1 招待コードを発行する

1. **マイチーム** を開きます
2. **招待コードを発行** を押します
3. 表示された26文字を、誘いたい人に伝えます

### ⚠️ コードは一度しか表示されません

画面を閉じたり、他のページへ移動したりすると**二度と表示できません。**
その場でコピーして、相手に送ってから閉じてください。

忘れてしまった場合は、もう一度 **招待コードを発行** を押せば新しいコードが出ます。
**ただし、前のコードは使えなくなります。**

### ⚠️ 有効なコードは常に1つだけ

新しく発行すると、前のコードは自動的に無効になります。
複数人を招待するときは、**1人ずつ順番に**発行して渡してください。

まとめて誘いたい場合は、次のようにします。

```text
1人目にコードを発行 → 渡す → 参加してもらう
   ↓
2人目にコードを発行 → 渡す → 参加してもらう
```

## 3.2 有効期限

発行から **24時間** です。過ぎたら発行し直してください。

---

# 4. 対戦相手を探す

## 4.1 マッチングを開始する

**リーダーだけが操作できます。**

1. ヘッダーの **マッチング** を押します
2. **マッチングを開始** を押します
3. 「対戦相手を探しています…」と表示されれば待機中です

相手が見つかると、自動的に試合が作られます。

## 4.2 すぐに相手が見つからないとき

「今は相手が見つかりませんでした。このまま待機します。」と表示されます。

**これは失敗ではありません。** 待機したままで、後から他のチームが
マッチングを始めたときに自動で組まれます。画面を閉じても待機は続きます。

## 4.3 ボタンが押せないとき

**マッチングを開始** ボタンが灰色で押せない場合、条件を満たしていません。
画面に理由が表示されます。

### 「チーム人数が足りません」

**人数が揃っていないと対戦できません。** 必要な人数は運営が決めており、
画面に「マッチングには◯人必要です（現在 ◯人）」と表示されます。

メンバーを招待して人数を揃えてください。

### 「進行中の試合があります」

**1つのチームが同時に持てる試合は1つだけ**です。
今の試合を終わらせてから、次のマッチングを始めてください。

## 4.4 待機をやめる

**待機をキャンセル** を押すと、待機列から外れます。
外れている間は対戦相手として選ばれません。

## 4.5 どうやって相手が決まるのか

**レートが近いチーム同士**が優先的に組まれます。
運営が決めた範囲（初期設定では400）を超えて離れているチームとは組まれません。

強すぎる相手・弱すぎる相手とは当たらない仕組みです。

# 5. 試合の結果を記録する

対戦が終わったら、結果をサイトに記録します。

## 5.1 全体の流れ

```text
【進行中】
   ↓  勝ったチームが「自チームの勝利を申告」
【承認待ち】
   ↓  負けたチームが「承認する」
【確定】→ レートが更新される
```

## 5.2 勝利を申告する（勝ったチーム）

1. ヘッダーの **試合** を押し、対象の試合を開きます
2. **自チームの勝利を申告** を押します

### 誰が押してもよい

**リーダーでなくても、チームの誰でも申告できます。**
先に気付いた人が押してください。

### 申告できるのは自分のチームの勝利だけ

「相手が勝った」と申告することはできません。**勝った側が申告する**仕組みです。

### ⚠️ 申告には期限があります

試合が始まってから **60分**（運営の設定によります）です。
画面に残り時間が表示されます。

**期限を過ぎると、引き分けとして解散します。** どちらのレートも変わりません。
対戦が終わったら早めに申告してください。

## 5.3 承認する（負けたチーム）

相手が勝利を申告すると、あなたの画面に **承認する** / **拒否する** が出ます。

内容が正しければ **承認する** を押します。これで試合が確定し、レートが更新されます。

### ⚠️ 承認にも期限があります

申告から **10分**（運営の設定によります）です。
画面に残り時間が表示されます。

**期限を過ぎると自動的に承認されます。** 相手の申告どおりに確定し、
レートが更新されます。放置しても試合は前に進みます。

異議がある場合は、期限内に **拒否する** を押してください。

## 5.4 拒否する

申告内容が事実と違う場合に使います。

**拒否する** を押すと、申告が取り消されて **進行中** に戻ります。
勝ったチームがもう一度申告し直せます。

### ⚠️ 拒否できる回数には上限があります

初期設定では **2回** です。画面に「拒否の残り回数」が表示されます。

**上限に達すると、引き分けとして解散します。** どちらのレートも変わりません。

拒否は「間違いを直すため」の機能です。話し合いがつかない場合は、
先に当事者間で確認してから記録してください。

## 5.5 試合の状態

| 表示 | 意味 | 次にすること |
| --- | --- | --- |
| **進行中** | 対戦中。まだ誰も申告していない | 勝ったチームが申告する |
| **承認待ち** | 申告済み。相手の返事待ち | 負けたチームが承認または拒否する |
| **確定** | 結果が確定。レート更新済み | 何もありません |
| **引き分け** | 時間切れか拒否上限で解散 | レートは変わっていません |

# 6. レートの見方

## 6.1 基本

- 新しいチームは **1500** から始まります
- 勝つと上がり、負けると下がります
- 引き分けでは変わりません

## 6.2 どれくらい動くのか

**相手との実力差によって変わります。**

| 状況 | 勝ったとき | 負けたとき |
| --- | --- | --- |
| 格上に勝った | 大きく上がる | — |
| 互角の相手に勝った | 中くらい上がる | — |
| 格下に勝った | 少ししか上がらない | — |
| 格上に負けた | — | 少ししか下がらない |
| 格下に負けた | — | 大きく下がる |

**格下に勝っても、あまり増えません。** 弱い相手ばかり選んでも上位には行けない、
という仕組みです。

## 6.3 増減の目安

初期設定（K値32）の場合、互角の相手との1試合でおよそ **16** 動きます。
実力差が大きいほど、この値から離れます。

## 6.4 下限

レートは **100** より下がりません。連敗しても0にはなりません。

## 6.5 増えた分と減った分

勝ったチームの増加と、負けたチームの減少は**同じ値**です。
全体の合計は変わりません。

ただしレートが下限に近いチームが負けた場合、下限で止まるため
減少分が小さくなることがあります。

# 7. ランキングを見る

ヘッダーの **ランキング** を押します。**ログインしていなくても見られます。**

全チームがレートの高い順に並びます。まだ1試合もしていないチームも表示されます。

# 8. チームの運営

## 8.1 メンバーを確認する

**マイチーム** に、チーム名・レート・人数・メンバー一覧が表示されます。
各メンバーには「リーダー」「メンバー」の区別が付いています。

## 8.2 リーダーを交代する（リーダー向け）

1. **マイチーム** を開きます
2. **リーダーの移譲** の欄で、交代したい相手の **◯◯ へ移譲** を押します

移譲すると、あなたは通常のメンバーになります。**元には戻せません**ので、
相手に確認してから実行してください。

## 8.3 チームを脱退する

**マイチーム** の下部にある **チームを脱退する** を押します。

### 脱退できない場合

| 表示されるメッセージ | 意味 | 対処 |
| --- | --- | --- |
| 先にリーダーを他のメンバーへ移譲してください | リーダーは、他にメンバーがいる状態では抜けられません | 8.2 で移譲してから脱退する |
| 試合中のため脱退できません | 進行中の試合があります | 試合を終わらせてから脱退する |

### 脱退すると

- チームから外れ、どこにも所属していない状態になります
- **待機中だった場合は、待機も自動で解除されます**
- チームのレートは変わりません（チームに紐づく数値のため）

### 最後の1人が脱退したとき

リーダー1人だけのチームは、そのまま脱退できます。
チーム名は残るため、**同じ名前で作り直すことはできません。**

# 9. 困ったときは

## 9.1 よくある症状

| 症状 | 原因 | 対処 |
| --- | --- | --- |
| ログインできない | — | 別のブラウザで試す。それでも駄目なら運営へ |
| マッチング開始が押せない | 人数不足・試合中 | 画面の説明を読む（4.3） |
| 招待コードが使えない | 期限切れ・使用済み | 新しいコードをもらう（2.2） |
| 相手が見つからない | 待機中のチームが他にいない | そのまま待つ。失敗ではありません |
| 勝ったのにレートが増えない | 相手が承認していない | 承認されるまで確定しません |
| 試合が引き分けになった | 期限切れか拒否上限 | 次の試合へ。レートは変わっていません |

## 9.2 「予期しないエラーが発生しました」と出たとき

一時的な不具合の可能性があります。次を試してください。

1. ページを再読み込みする
2. 数分待ってからもう一度試す
3. それでも直らない場合は運営へ連絡する

## 9.3 操作が反映されないとき

複数人が同時に同じ試合を操作すると、後から押した方が
エラーになることがあります。**ページを再読み込みしてから**やり直してください。

# 10. マナーと注意

## 10.1 結果は正直に記録する

レートは全員の記録の積み重ねで成り立っています。
虚偽の申告はランキング全体の信頼を損ないます。

## 10.2 期限内に操作する

申告と承認には期限があります。放置すると引き分けになり、
**対戦した意味がなくなります。** 対戦が終わったらその場で記録するのが確実です。

## 10.3 待機したままにしない

対戦する予定がなくなったら、**待機をキャンセル** してください。
待機したままだと、相手が試合を組んだのに応答がない状態になります。

## 10.4 招待コードを公開しない

招待コードを知っている人は誰でもチームに入れます。
SNS などに貼らず、招待したい相手にだけ直接渡してください。

# 11. 用語集

| 言葉 | 意味 |
| --- | --- |
| レート | チームの強さを表す数値。1500 から始まる |
| リーダー | チームの代表者。招待の発行とマッチング開始ができる |
| メンバー | リーダー以外の所属者。結果の申告と承認はできる |
| 招待コード | チームに参加するための26文字の文字列。有効期限24時間 |
| マッチング | 対戦相手を自動で探す仕組み |
| 待機 | 対戦相手を探している状態 |
| 申告 | 勝ったチームが結果を報告すること |
| 承認 | 負けたチームが結果を認めること |
| 確定 | 結果が決まり、レートが更新された状態 |
| 引き分け | 期限切れか拒否上限で解散した状態。レートは変わらない |
| K値 | レートの動きやすさを決める設定。運営が変更できる |
